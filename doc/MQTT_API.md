# MQTT心跳协议

本文档用于描述各被监控主机向服务端的心跳报文格式

## 主题

上报心跳的主题为 `OPS-PANEL`

## 报文格式

总体报文为JSON格式，包括被监控主机的基本情况、磁盘占用、服务运行情况；其中，各主机、磁盘、服务ID取自系统，应在系统自动生成后在被监控主机的配置文件中进行配置。

```json
{
    "id": 114514,
    "cpuUsage": 0.114,
    "ramUsage": 0.514,
    "disks": [
        {
            "id": 223,
            "diskUsage": 0.7355
        },
        {
            "id": 666,
            "diskUsage": 0.608
        }
    ],
    "services": [
        {
            "id": 114,
            "online": true
        },
        {
            "id": 514,
            "online": false
        }
    ]
}
```
